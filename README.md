# 📊 Grade Tracker

> A modern, responsive, and lightweight web application designed to calculate and track your academic grades seamlessly—with zero backend required.

---

## ✨ Features

- **⚡ Zero Backend / Client-Side First:** Fast, private, and runs entirely in your browser.
- **🎯 Dynamic Calculations:** Instantly compute overall averages, weighted categories, and term grades.
- **📱 Responsive UI:** Clean and minimal design optimized for both desktop and mobile views.
- **🔒 Data Privacy:** No accounts, databases, or tracking.
